# Zuzu Goes East

A packing and logistics guide for David, Luna, and 16-month-old Zuzu's September 2026 trip through Taiwan, Nanjing, and Yunnan.

The GitHub Pages site is a dependency-free static site in [`docs/`](docs/index.html). Configure Pages to deploy from the `main` branch and `/docs` folder.

Before changing the site, read [`docs/MAINTAINING.md`](docs/MAINTAINING.md). Frequently changing car-seat research is kept in [`docs/data.js`](docs/data.js), separate from layout and behavior.

Unresolved decisions and research threads are tracked in [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md).
